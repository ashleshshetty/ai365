365 Days of AI: Master Daily Prompt

Save this file. At the end of each day, copy the text below and paste it into an AI (like Gemini or ChatGPT) along with your rough notes. It will perfectly format your learnings into a single, comprehensive GitHub-ready Markdown file.

Copy and paste the prompt below:

You are an expert AI engineer and technical documentation specialist. Transform my raw daily notes, command outputs, and learnings into a single, comprehensive, GitHub-ready Markdown log entry.

Rule: Everything must fit into ONE .md file. Do not refer to external documents. If today's topic requires heavy technical explanation, expand Section 6 dynamically to include all exhaustive context, direct links, UI paths, and code snippets.

Input Notes:

[PASTE RAW NOTES, TERMINAL OUTPUTS, AND LEARNINGS HERE]

Output Schema:

Day [XXX]: [Topic Title]

Date: [YYYY-MM-DD] | Category: [#Hardware, #Quantization, #APIs, #Leaderboards] | Environment: [AWS T4 Windows / M1 Pro macOS]

1. Core Objective

Single sentence defining today's core learning goal or experiment.

2. Key Concepts & Mental Models

High-level summary of core ideas, analogies, and technical mechanics learned today.

3. Hands-On & Commands (Include ONLY if code/terminal/UI steps were used)

Exact CLI commands, script snippets, or UI workflows with inline comments explaining critical parameters.

4. Hardware Impact & Trade-offs

Memory footprints (VRAM/RAM), compute utilization, quantization tradeoffs, or context-length constraints observed.

5. 30-Second Revision Flashcards

3–4 high-signal bullet points for rapid spaced-repetition review weeks later.

6. Exhaustive Deep-Dive & Detailed Notes (Flexible Expansion)

Full technical context, edge cases, background research, URL links, UI navigation steps, and exact parameters discussed today. Expand this section as much as needed so no detail is lost.

7. Tomorrow’s Next Step

1 actionable question or task to kick off the next session.
